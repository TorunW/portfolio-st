# Wedding budget tracker

A simple standalone wedding budget calculator. Your budget and expenses are saved in the browser with `localStorage`, so they persist when you close and reopen the site.

## Deploy on Vercel

1. Create a **new** GitHub repository (do not use the portfolio repo).
2. Push this project to that repository.
3. In [Vercel](https://vercel.com/new), import the new repo.
4. Deploy with the default settings (static site / no build needed).

Your site will be live at `https://<project-name>.vercel.app`.

## Local preview

Open `index.html` in a browser, or run:

```bash
npx serve .
```
